Book My Seat – Movie Ticket Booking System

Overview:-
Book My Seat is a standalone desktop-based Movie Ticket Booking System developed using Python, Tkinter, and SQLite3. The application provides an intuitive graphical user interface for managing movies, theatres, seat reservations, ticket bookings, payments, and cancellations.
The project was developed as an academic desktop application to demonstrate concepts of GUI development, database management, and modular programming using Python.

Features:-
• Secure Admin Login
• Movie Management
• Theatre Management
• Seat Booking and Availability Management
• Ticket Booking with Calendar Integration
• Payment Management
• Ticket Cancellation
• SQLite3 Database Integration
• User-Friendly Graphical Interface

Technologies Used:-
• Python 3
• Tkinter
• SQLite3
• Pillow (PIL)
• Calendar Module

Database Structure:-
The application automatically creates and manages the following database tables:

• Seats
• Bookings
• Payments
• Cancellations

Install Required Dependencies
